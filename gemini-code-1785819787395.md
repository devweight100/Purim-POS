## 📦 CORE DOMAIN LOGIC & DATA MODELS

### 1. Multi-Barcode & FIFO Costing Architecture
- **Products & Variants (SKU):** Master entity `Product` tied to unique SKUs.
- **Multi-Barcode Entity (`ProductBarcode`):** One SKU can be linked to multiple barcodes supplied by different vendors with different purchase costs.
- **Inventory Valuation (Strict FIFO):**
  - Implement a `StockBatch` table tracking `id`, `product_id`, `barcode_id`, `quantity_remaining`, `unit_cost`, `received_at`.
  - When an item is scanned/sold, deduct inventory using **First-In, First-Out (FIFO)** based on `StockBatch`. Calculate Cost of Goods Sold (COGS) dynamically per line item.
- **Multi-Branch Inventory Sync:** Instant real-time stock transfer updates between branches.

### 2. Smart Claim & Warranty System (No-Receipt Return & Store Credit Offset)
- **Receipt-less Lookup Algorithm:** Cashiers can search order history via `[Customer Phone/Name]` + `[Product SKU/Barcode]`.
- **Override Claim Mode:** Allow cashiers to bypass validation (e.g., items bought prior to system onboarding) ONLY IF they provide mandatory `Reason Code` + `Notes`.
- **Claim Compensation Options:**
  1. *Alternative Product Exchange / Upgrade:* If exchanging for a higher-priced item (e.g., old item = $10, new item = $15), generate a temporary `CreditNote` ($10) and apply it as a discount offset to the new sale bill (net payable = $5).
  2. *Cash Refund:* Process refund via specified payment methods. Accounting MUST log claims as "Warranty Expense / Claims Cost".

### 3. Split Payment Engine & Hardware Events
- **Split Payments:** Support combining multiple payment methods in a single checkout session (Cash + PromptPay/QR + Credit Card + Point Redemption).
- **Hardware Integration:** One-click `Re-print Last Receipt` functionality. Trigger automatic cash drawer pulse commands (`ESC/POS` signals) exclusively on cash payments or cash refunds.

### 4. Procurement & Supplier Management (PO & Goods Receiving)
- **Supplier Directory (`Supplier`):** Manage supplier details, lead times, and credit terms (e.g., Net 30, Net 60) for AP integration.
- **Purchase Order (PO) Workflow:**
  - Create PO linking `Supplier` and `Products`.
  - Define expected cost and quantity. Support PO status tracking (Draft, Pending Approval, Issued, Partially Received, Completed).
- **Goods Receipt Note (GRN) & AP Trigger:**
  - When goods arrive, users perform a "Receive Items" action against a specific PO.
  - *CRITICAL:* Receiving goods MUST automatically generate a new `StockBatch` with the exact `unit_cost` from the PO for future FIFO calculations.
  - Automatically create an Accounts Payable (AP) invoice based on the received quantity and supplier's credit terms.

### 5. Customer Relationship Management (CRM) & Loyalty
- **Member Management (`Customer`):** Full CRUD for customer profiles, linking to their complete purchase history and active credit notes.
- **Dynamic Loyalty Points:** Customizable point earning rules (e.g., $100 = 1 point) and redemption values configurable via the Admin panel.

### 6. Omnichannel Real-time Sync (LINE Shopping & Web Store)
- Centralized inventory database enforcing locking mechanisms (`SELECT FOR UPDATE`) during checkout.
- Instant stock deduction across both physical POS terminals and Web/LINE Shopping stores.
