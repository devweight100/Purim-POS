# 04 — สถาปัตยกรรม Frontend และ State Management

## 2. การจัดการสถานะด้วย Zustand (State Stores)

### 2.1 Cart Store (`frontend/src/lib/store/cart-store.ts`)
จัดการตะกร้าสินค้าในหน้า POS โดยมีความสามารถพิเศษ:
- **พักบิล / เรียกบิล (Hold & Recall Carts)**: แคชเชียร์สามารถพักบิลลูกค้าคนที่ 1 เพื่อคิดเงินลูกค้าคนที่ 2 ก่อน แล้วกดเรียกบิลเดิมกลับมาได้ไม่จำกัดจำนวน
- **Smart Rollup**: ทุกครั้งที่มีการเพิ่ม/ลดจำนวนสินค้า ตะกร้าจะเรียก `calculateSmartRollupAndPricing()` เพื่อปรับหน่วยบรรจุภัณฑ์และราคาส่งอัตโนมัติ
- **Customer Selection**: ผูกแต้มสะสมและสิทธิ์เครดิตเงินเชื่อกับบิล

```typescript
// โครงสร้าง CartItem
interface CartItem {
  id: string;              // unique row id
  productId: string;
  name: string;
  sku: string;
  unit: string;
  quantity: number;
  conversionFactor: number;// ตัวคูณหน่วยฐาน (เช่น ลัง = 48 ชิ้น)
  unitPrice: number;
  originalPrice: number;
  customPrice: number | null;
  discountType: 'none' | 'percent' | 'amount';
  discountValue: number;
  totalPrice: number;
  barcode?: string;
}
```

### 2.2 Shift Store (`frontend/src/lib/store/shift-store.ts`)
- ติดตามกะปัจจุบัน (`activeShift`)
- บันทึกการเปิดกะด้วยเงินทอนเริ่มต้น (`startingCash`)
- ติดตามยอดเงินสดในลิ้นชักแบบ Real-Time จากยอดขายเงินสด + Cash In - Cash Out
- แจ้งเตือนแคชเชียร์ให้เปิดกะก่อนเริ่มขายสินค้า

### 2.3 Product Store (`frontend/src/lib/store/product-store.ts`)
- เก็บแคชรายการสินค้าทั้งหมดไว้ใน Memory ฝั่งเบราว์เซอร์ เพื่อให้การสแกนบาร์โค้ดตอบสนองได้ทันที (Latency < 5ms) โดยไม่ต้องยิง API หาเซิร์ฟเวอร์ทุกครั้งที่สแกน
- รองรับการค้นหาแบบ Full-Text ข้าม SKU, ชื่อสินค้า, และบาร์โค้ดทุกชุด

### 2.4 Auth Store (`frontend/src/lib/store/auth-store.ts`)
- เก็บ JWT Access Token และข้อมูลสิทธิ์ (`UserRole`) ใน Memory + Cookie/Session
- ฟังก์ชันตรวจสอบสิทธิ์ `hasPermission(role, requiredRole)`

## 3. ผังปุ่มลัดคีย์บอร์ดสำหรับแคชเชียร์หน้าร้าน (Cashier Keyboard Shortcuts)

หน้าจอ POS ถูกออกแบบให้ **แคชเชียร์สามารถปิดการขายได้โดยไม่ต้องแตะเมาส์แม้แต่ครั้งเดียว**:

| ปุ่มลัด | ฟังก์ชันการทำงาน | รายละเอียด |
| :---: | :--- | :--- |
| **`F1`** | **ช่วยเหลือ (Help)** | เปิดหน้าต่างสรุปปุ่มลัดทั้งหมดในหน้าจอขาย |
| **`F2`** | **ค้นหาสินค้า (Search)** | เปิด Modal ค้นหาสินค้าด้วยชื่อ หรือหมวดหมู่ |
| **`F3`** | **สแกนบาร์โค้ด (Focus Barcode)** | ดึง Cursor กลับมาที่ช่องกรอก/สแกนบาร์โค้ดทันที |
| **`F4`** | **พักบิล / เรียกคืนบิล (Hold Cart)** | สลับหน้าต่างพักบิลปัจจุบัน หรือเลือกบิลที่พักไว้กลับมาขายต่อ |
| **`F7`** | **สินค้าไม่มีบาร์โค้ด (Custom Item)** | ใส่ชื่อและราคาสินค้าจรที่ไม่มีในระบบ |
| **`F8`** | **เลือกลูกค้า / สมาชิก (Member)** | ค้นหาลูกค้าด้วยเบอร์โทร เพื่อสะสมแต้มหรือให้เครดิต |
| **`F9`** | **เตะลิ้นชักเก็บเงิน (Kick Drawer)** | ส่งสัญญาณเปิดลิ้นชักเก็บเงินทันที (ไม่ต้องรอปิดบิล) |
| **`F10`** | **ชำระด้วยเงินสด (Cash Payment)** | เปิดหน้าต่างรับเงินสด พร้อมปุ่มลัดจำนวนเงินด่วน (เช่น 100, 500, 1000) |
| **`F11`** | **ชำระด้วย QR PromptPay** | สร้าง Dynamic PromptPay QR Code ตามยอดเงินที่ต้องชำระ |
| **`F12`** | **ยืนยันการชำระเงิน (Confirm & Print)** | บันทึกออเดอร์, ตัดสต็อก, เตะลิ้นชัก และพิมพ์ใบเสร็จ |
| **`ESC`** | **ยกเลิก / ปิดหน้าต่าง (Cancel)** | ปิด Modal ที่เปิดอยู่ หรือล้างช่องค้นหา |
| **`+` / `-`** | **ปรับจำนวนสินค้า (Qty +/-)** | เพิ่มหรือลดจำนวนสินค้าของแถวที่เลือกอยู่ |
| **`Delete`** | **ลบแถวสินค้า (Remove Item)** | นำสินค้าแถวที่เลือกออกจากตะกร้า |

## 4. มาตรฐานการแสดงผลและการจัดรูปแบบ (Formatting Standards)

1. **สกุลเงิน (Thai Baht)**: แสดงสัญลักษณ์ `฿` พร้อมทศนิยม 2 ตำแหน่งเสมอ เช่น `฿1,250.00`
2. **วันที่และเวลา**: แสดงตาม พ.ศ. หรือ ค.ศ. แบบสากล ภาษาไทย เช่น `26 ต.ค. 2569 14:05 น.`
3. **การแจ้งเตือน (Notifications)**: ใช้ `Sonner` Toast แสดงความสำเร็จ (`toast.success`) หรือข้อผิดพลาด (`toast.error`) ที่มุมขวาบนของจอภาพ
