คู่มือเปิดร้านออนไลน์ใน LINE (ลูกค้ากด "🛒 สั่งของ" ใน LINE ร้าน) — ร้านปุริม POS
=====================================================================================

ภาพรวม
  ลูกค้ากดเมนู "🛒 สั่งของ" ใน LINE Official Account ของร้าน > เปิดหน้าร้านในแอป LINE (LIFF)
  > เลือกสินค้า ใส่ตะกร้า เลือก "รับเองที่ร้าน" หรือ "ให้ร้านไปส่ง" > ส่งออเดอร์
  ออเดอร์เด้งที่หน้า "ออเดอร์ออนไลน์ (LINE)" ในระบบหลังบ้าน (มีเสียง + ตัวเลขแจ้งเตือน)
  พนักงานตรวจ ใส่ค่าส่ง กด "รับออเดอร์" > ไปรับเงินที่หน้าขาย (ปุ่ม "บิลพัก" > "เปิดบิล")

  สิ่งที่ต้องมี: LINE Official Account ของร้าน, บัญชี LINE Developers (ฟรี), โดเมนของร้าน (ปีละไม่กี่ร้อยบาท),
  บัญชี Cloudflare (ฟรี) และเครื่องแม่ (Server) ที่เปิดอยู่ตลอดเวลาที่รับออเดอร์

  ความปลอดภัย: จากอินเทอร์เน็ตเข้าได้ "เฉพาะหน้าร้านออนไลน์" เท่านั้น (/shop และข้อมูลสินค้าที่ลูกค้าเห็น)
  หน้าขาย หลังบ้าน รายงาน และข้อมูลอื่นทั้งหมด เข้าจากนอกร้านผ่านโดเมนนี้ไม่ได้ (ระบบตอบ 404)
  ราคาทุน ผู้จำหน่าย จำนวนสต็อก และข้อมูลลูกค้าคนอื่น ไม่ถูกส่งออกไปเลย ลูกค้าเห็นแค่ "มีของ / หมด"


ขั้นที่ 0  ทดลองในร้านก่อน (ยังไม่ต้องตั้งค่า LINE)
------------------------------------------------------
  1. เข้าหลังบ้านด้วยบัญชี admin > ตั้งค่า > แท็บ "ร้านออนไลน์ (LINE)" > ติ๊ก "เปิดรับออเดอร์ออนไลน์" > บันทึก
  2. ที่เครื่องในร้าน (หรือมือถือที่ต่อ Wi-Fi ร้าน) เปิด  http://<IP เครื่องแม่>:3000/shop
     จะเห็นแถบเหลือง "โหมดทดสอบ" ลองสั่งของได้เลย ออเดอร์จะเข้าหน้า "ออเดอร์ออนไลน์ (LINE)"
  3. โหมดทดสอบใช้ได้เฉพาะในร้าน และจะปิดเองเมื่อใส่ LIFF ID + Channel ID แล้ว


ขั้นที่ 1  LINE Official Account (บัญชี LINE ของร้าน)
------------------------------------------------------
  1. เข้า https://manager.line.biz ล็อกอินด้วย LINE ของเจ้าของ > สร้างบัญชี (ถ้ามีแล้วข้ามได้)
  2. ในบัญชีร้าน: ตั้งค่า (Settings) > Messaging API > กด "ใช้ Messaging API" (Enable)
     > เลือก/สร้าง Provider (ชื่อร้าน) — ระบบจะสร้าง "Messaging API channel" ให้ใน LINE Developers


ขั้นที่ 2  LINE Developers: token สำหรับส่งข้อความ + LIFF สำหรับหน้าร้าน
-------------------------------------------------------------------------
  เข้า https://developers.line.biz/console/ (ล็อกอินบัญชีเดียวกัน) > เลือก Provider ของร้าน

  2.1 Messaging API channel (ที่ได้จากขั้นที่ 1)
      แท็บ "Messaging API" > Channel access token (long-lived) > กด Issue > คัดลอกเก็บไว้
      (ใช้ส่งข้อความแจ้งลูกค้า: ได้รับออเดอร์ / ยืนยันพร้อม QR พร้อมเพย์ / ยกเลิก / กำลังส่ง / เสร็จ)

  2.2 สร้าง "LINE Login channel" ใน Provider เดียวกัน (Create a new channel > LINE Login)
      - App types: ติ๊ก Web app
      - หลังสร้าง: แท็บ Basic settings > จด "Channel ID" (ตัวเลข)
      - แท็บ LIFF > Add
          LIFF app name: สั่งของ
          Size: Full
          Endpoint URL: https://<โดเมนร้าน>/shop        เช่น https://shop.purimshop.com/shop
          Scopes: ติ๊ก openid และ profile
          Bot link feature: On (Aggressive)   (ลูกค้าจะถูกชวนเพิ่มเพื่อน LINE ร้าน เพื่อรับข้อความแจ้งออเดอร์)
        > Add แล้วจด "LIFF ID" (รูปแบบ 1234567890-AbCdEfGh)
      - สำคัญ: กดเปลี่ยนสถานะ channel จาก "Developing" เป็น "Published" (มุมบนของหน้า channel)
        ถ้ายังเป็น Developing ลูกค้าทั่วไปจะเปิดหน้าร้านไม่ได้

  2.3 ใส่ค่าในระบบ: หลังบ้าน > ตั้งค่า > "ร้านออนไลน์ (LINE)"
        LIFF ID, Channel ID ของ LINE Login, Channel access token, ที่อยู่เว็บร้าน (https://<โดเมนร้าน>)
      > บันทึก > กด "ทดสอบการเชื่อมต่อ LINE" (ต้องขึ้นชื่อบัญชี LINE ร้าน)
      token เก็บที่เครื่องแม่เท่านั้น ไม่แสดงกลับมาอีก (ถ้าจะเปลี่ยนให้วางตัวใหม่ทับ)


ขั้นที่ 3  โดเมนของร้าน + Cloudflare (ฟรี)
-------------------------------------------
  1. ซื้อโดเมน (เช่น purimshop.com) จากผู้ให้บริการใดก็ได้ หรือซื้อใน Cloudflare Registrar
  2. สมัคร https://dash.cloudflare.com (แพ็กเกจ Free) > Add a domain > ใส่โดเมน
  3. Cloudflare จะให้ nameserver 2 ตัว > ไปที่เว็บที่ซื้อโดเมน เปลี่ยน nameserver เป็น 2 ตัวนั้น
     รอจนในหน้า Cloudflare ขึ้นสถานะ Active (ปกติไม่กี่นาที บางครั้งถึง 24 ชม.)


ขั้นที่ 4  Cloudflare Tunnel บนเครื่องแม่ (ไม่ต้องเปิดพอร์ตเราเตอร์ ไม่ต้องมี IP จริง)
-----------------------------------------------------------------------------------------
  4.1 ใน https://one.dash.cloudflare.com (Zero Trust; ครั้งแรกให้ตั้งชื่อทีมและเลือกแพ็กเกจ Free)
      Networks > Tunnels > Create a tunnel > Cloudflared > ตั้งชื่อ เช่น purim-shop > Save
      หน้าถัดไปเลือก Windows จะเห็นคำสั่งที่มี token ยาว ๆ (ขึ้นต้นด้วย eyJ...) — คัดลอก "เฉพาะ token"
  4.2 แท็บ Public Hostname (Route tunnel) > Add a public hostname
        Subdomain: shop      Domain: <โดเมนร้าน>      Path: (เว้นว่าง)
        Service:  Type = HTTP   URL = localhost:3080
      > Save
      *** ต้องเป็นพอร์ต 3080 เท่านั้น *** (พอร์ตนี้ของระบบเปิดให้เฉพาะหน้าร้านออนไลน์)
      ห้ามชี้ไปที่ 3000 หรือ 3001 (ระบบมีกันไว้อีกชั้นแล้ว แต่ตั้งให้ถูกตั้งแต่แรก)
  4.3 ที่เครื่องแม่: เปิด PowerShell แบบ "Run as administrator" แล้วพิมพ์ (บรรทัดเดียว)
        powershell -ExecutionPolicy Bypass -File "C:\PurimPOS\Installer\Server\setup\setup-cloudflare-tunnel.ps1" -Token <token> -Hostname shop.<โดเมนร้าน>
      สคริปต์จะ: ติดตั้ง cloudflared (ถ้ายังไม่มี), ติดตั้งเป็น Windows service (เปิดเองทุกครั้งที่เปิดเครื่อง),
      บันทึกชื่อโดเมนร้านให้ระบบ (SHOP_PUBLIC_HOST) และตรวจว่าพอร์ต 3080 เปิดเฉพาะหน้าร้าน
      (ถ้าติดตั้งไว้ที่อื่นที่ไม่ใช่ C:\PurimPOS ให้แก้ path ตามจริง)
  4.4 รีสตาร์ทเซิร์ฟเวอร์จากโปรแกรม "Purim POS Server" 1 ครั้ง
  - ยกเลิก tunnel:  ... setup-cloudflare-tunnel.ps1 -Uninstall


ขั้นที่ 5  ตรวจความปลอดภัย (ทำทุกครั้งหลังตั้งค่า) — ใช้มือถือที่ปิด Wi-Fi (ใช้เน็ตมือถือ)
-------------------------------------------------------------------------------------------
  https://shop.<โดเมนร้าน>/shop        ต้องเปิดได้ (นอก LINE จะพาไปล็อกอิน LINE)
  https://shop.<โดเมนร้าน>/pos         ต้องขึ้น Not Found
  https://shop.<โดเมนร้าน>/login       ต้องขึ้น Not Found
  https://shop.<โดเมนร้าน>/api/products   ต้องขึ้น Not Found
  ถ้าข้อใดเปิดได้ ให้ปิด tunnel ทันที (Zero Trust > Tunnels > ลบ public hostname) แล้วตรวจขั้นที่ 4.2


ขั้นที่ 6  ปุ่ม "🛒 สั่งของ" ใน LINE ร้าน (Rich menu)
-----------------------------------------------------
  https://manager.line.biz > บัญชีร้าน > หน้าหลัก > ริชเมนู (Rich menus) > สร้าง
  - เลือกเทมเพลต วางรูปปุ่ม "🛒 สั่งของ"
  - การกระทำ (Action): ลิงก์ (Link) > https://liff.line.me/<LIFF ID>
  - ช่วงเวลาแสดง: ไม่กำหนด > บันทึก (สถานะ "เปิด")
  ลูกค้าที่แอด LINE ร้านแล้วจะเห็นปุ่มด้านล่างแชท


ใช้งานประจำวัน
--------------
  • ราคา: ลูกค้าทั่วไปเห็น "ราคาปลีก" (ราคาระดับ 1)
    ลูกค้าประจำกด "ผูกบัญชี" ในหน้าร้าน แล้วกรอกเบอร์ > คำขอเข้าที่หน้า "ออเดอร์ออนไลน์ (LINE)" แท็บ "คำขอผูกสมาชิก"
    ให้ผู้จัดการ/ผู้มีสิทธิ์ให้ส่วนลด ตรวจว่าเป็นเจ้าของเบอร์จริง (โทรกลับ) แล้วกด "ผูกกับ..." — ไม่ผูกอัตโนมัติ
    หลังผูก ลูกค้าเห็นราคาตามระดับราคาของสมาชิก (ตั้งชื่อราคาได้ที่ ตั้งค่า > ร้านออนไลน์)
  • ค่าส่ง: ตั้งต่อสมาชิกที่หน้า "ลูกค้าสมาชิก" > แก้ไข > ช่อง "ค่าส่ง (ร้านออนไลน์ LINE)" (เช่น 50-120 บาท)
    ลูกค้าที่ยังไม่ผูก/สมาชิกที่ไม่ได้ตั้งค่าส่ง จะเห็น "ร้านจะแจ้งค่าส่ง" — พนักงานใส่ค่าส่งก่อนกดรับออเดอร์
    รับเองที่ร้าน = ไม่มีค่าส่ง; ค่าส่งเข้าบิลเป็นรายการ "ค่าส่ง" (ไม่ตัดสต็อก)
  • รับเงิน: หน้าขาย > ปุ่ม "บิลพัก" > หัวข้อ "ออเดอร์ออนไลน์ (LINE) รอชำระ" > "เปิดบิล" > ชำระเงินตามปกติ
    (เงินสด / QR / เงินเชื่อ) — ออเดอร์แบบรับที่ร้านจะปิดเป็น "เสร็จแล้ว" อัตโนมัติ
    แบบส่งของ: หลังส่งให้กด "กำลังไปส่ง" / "เสร็จแล้ว" ในหน้าออเดอร์ (ลูกค้าได้ข้อความ LINE ทุกครั้ง)
  • QR พร้อมเพย์ในข้อความ LINE ต้องตั้ง PromptPay ID ที่บัญชีธนาคารหลัก (หน้า บัญชีธนาคาร & QR Code)
  • เครื่องแม่ต้องเปิดอยู่ ลูกค้าจึงจะสั่งได้ (ปิดเครื่อง = หน้าร้านขึ้น "ร้านปิดชั่วคราว")
  • ปิดรับออเดอร์ชั่วคราว: ตั้งค่า > ร้านออนไลน์ > เอาติ๊ก "เปิดรับออเดอร์ออนไลน์" ออก

ปัญหาที่พบบ่อย
--------------
  • ลูกค้าเปิดแล้วขึ้น "ร้านยังไม่เปิดรับออเดอร์ออนไลน์": ยังไม่ได้ติ๊กเปิดรับ หรือยังไม่ได้ใส่ LIFF ID + Channel ID
  • เปิดจาก LINE แล้วขึ้น "LINE ไม่ยืนยันตัวตน": Channel ID ไม่ตรงกับ LINE Login channel ที่มี LIFF นี้
  • ลูกค้าไม่ได้รับข้อความ LINE: ยังไม่ได้ใส่ token / ลูกค้ายังไม่ได้เพิ่มเพื่อน LINE ร้าน / ดูบรรทัด "LINE:" ในรายละเอียดออเดอร์
  • หน้าร้านขึ้น 502 / ร้านปิดชั่วคราว: เซิร์ฟเวอร์ปิดอยู่ หรือ service "Cloudflared agent" หยุด (Windows > services.msc)
