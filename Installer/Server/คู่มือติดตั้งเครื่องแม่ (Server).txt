คู่มือติดตั้งเครื่องแม่ (Server) — ร้านปุริม POS
=====================================================

ไฟล์ติดตั้ง:  Purim-POS-Server-Setup.exe   (ใช้กับเครื่องแม่เพียง 1 เครื่อง)
ดาวน์โหลด:   https://github.com/devweight100/Purim-POS/releases/latest
             (repo แบบ private: login GitHub ด้วยบัญชีที่มีสิทธิ์ก่อน แล้วกดชื่อไฟล์ในหัวข้อ Assets)
             ตรวจไฟล์ครบ: PowerShell > Get-FileHash .\Purim-POS-Server-Setup.exe เทียบกับ SHA256SUMS.txt

สิ่งที่ต้องมีก่อน
  • Windows 10/11 64-bit, RAM 8GB ขึ้นไป, พื้นที่ว่าง 15GB
  • ต่ออินเทอร์เน็ตระหว่างติดตั้ง (ดาวน์โหลด Node.js / Docker / แพ็กเกจ)
  • ตั้ง IP เครื่องแม่ให้คงที่ในเราเตอร์ (DHCP reservation) จะดีที่สุด

ขั้นตอนติดตั้ง
  1. ดับเบิลคลิก Purim-POS-Server-Setup.exe > กด Yes (สิทธิ์ Administrator)
  2. เลือกโฟลเดอร์ (ค่าเริ่มต้น C:\PurimPOS) > ติดตั้ง
  3. จะมีหน้าต่างสีน้ำเงินแสดงความคืบหน้า 8 ขั้นตอน รอจนขึ้น "ติดตั้งเสร็จเรียบร้อย" แล้วกด Enter
     - ถ้าเครื่องยังไม่มี Docker Desktop ตัวติดตั้งจะลงให้ แล้วขอให้รีสตาร์ทเครื่อง 1 ครั้ง
       หลังรีสตาร์ท: เปิด Docker Desktop กด Accept ให้ขึ้น Engine running
       แล้วเปิด Start > Purim POS Server > "ติดตั้งหรือซ่อมระบบ Purim POS" เพื่อทำต่อให้เสร็จ
  4. เสร็จแล้วหน้าจอจะแสดงที่อยู่สำหรับเครื่องลูก เช่น http://192.168.1.20:3000

ติดตั้งครั้งแรก (ฐานข้อมูลใหม่) — บัญชีเริ่มต้น
  admin / admin123   (PIN 1234)     cashier1 / cashier123   (PIN 0000)
  ระบบจะบังคับให้เปลี่ยนรหัสผ่านและ PIN ตอนเข้าครั้งแรก

อัปเดตเวอร์ชันใหม่ (เครื่องที่ใช้งานอยู่แล้ว)
  • วิธีง่ายสุด: ปุ่ม "อัปเดตระบบ (GitHub)" ด้านล่าง
  • หรือดาวน์โหลดไฟล์ติดตั้งตัวใหม่จาก Releases แล้วรันทับได้เลย ข้อมูลร้านเดิมอยู่ครบ
  • ก่อนอัปเดตระบบจะสำรองฐานข้อมูลให้อัตโนมัติที่ backend\backups\pre-update-*.dump
  • ถ้าเดิมรันจากโฟลเดอร์ git (START_SERVER.bat) ตัวติดตั้งจะใช้ฐานข้อมูลเดิม (pos-purim-db)
    และคัดลอก .env, รูปสินค้า (uploads) และไฟล์สำรองมาให้ — หลังติดตั้งให้ใช้โปรแกรม Purim POS Server แทน START_SERVER.bat
  • ฐานข้อมูลที่เคย migrate ไม่ผ่าน (P3018/P3009) ตัวติดตั้งจะซ่อมประวัติ migration ให้อัตโนมัติ

ใช้งานประจำวัน
  • เปิดเครื่อง + เข้า Windows แล้วเซิร์ฟเวอร์เปิดเอง ไม่ต้องกดอะไร
  • โปรแกรม "Purim POS Server" (ไอคอนโลโก้ที่มุมขวาล่างของจอ / เมนู Start > Purim POS Server)
      - ดูสถานะ: เซิร์ฟเวอร์ / ระบบหลังบ้าน+ฐานข้อมูล / หน้าจอขาย (ไฟเขียว = พร้อม)
      - ปุ่ม เริ่ม / หยุด / รีสตาร์ท เซิร์ฟเวอร์
      - ปุ่ม เปิดแอป, มอนิเตอร์ร้าน, โฟลเดอร์ log/ไฟล์สำรอง
      - แสดงที่อยู่สำหรับเครื่องลูก และบันทึกการทำงานล่าสุด
      - ปิดหน้าต่างได้ เซิร์ฟเวอร์ยังทำงานต่อ (ย่อไปอยู่มุมขวาล่าง)
  • บนหน้าจอมีไอคอนแอป "ร้านปุริม POS" อย่างเดียว (ติดตั้งให้พร้อมเซิร์ฟเวอร์)
  • ถ้าโปรแกรมหลังบ้าน/หน้าจอค้าง ระบบจะเริ่มใหม่ให้เอง
  • Docker Desktop ต้องเปิดอยู่เสมอ (ฐานข้อมูลอยู่ในนั้น) — ตั้งค่า Start when you sign in ไว้แล้ว

อัปเดตจาก GitHub Releases (ไม่ต้องดาวน์โหลดไฟล์ติดตั้งเอง)
  • เข้าสู่ระบบด้วยบัญชี admin > เมนู "มอนิเตอร์ร้าน (Pixel View)" > กล่อง "อัปเดตระบบ (GitHub)"
  • ครั้งแรกจะขอ GitHub token แบบอ่านอย่างเดียว (ใส่ครั้งเดียว เก็บเข้ารหัสในเครื่องแม่):
      github.com > Settings > Developer settings > Fine-grained tokens > Generate new token
      Repository access: Only select repositories > devweight100/Purim-POS
      Permissions > Contents: Read-only > Generate แล้ว copy มาวาง
  • กด "ตรวจสอบเวอร์ชันใหม่" ระบบเทียบเวอร์ชันที่ติดตั้ง (เช่น v1.5.0) กับ Release ล่าสุดบน GitHub
    ถ้ามีเวอร์ชันใหม่จะมีปุ่ม "อัปเดตเป็น v..." ให้กดยืนยัน
  • ระบบดาวน์โหลดไฟล์ของ Release และตรวจ SHA-256 ให้ครบก่อน แล้วจึงหยุดเซิร์ฟเวอร์
    (ดาวน์โหลดไม่สำเร็จ = ไม่มีอะไรเปลี่ยน ร้านขายต่อได้)
  • อัปเดต = สำรองข้อมูล > อัปเดตฐานข้อมูล > build > เปิดเซิร์ฟเวอร์ใหม่ (เครื่องขายใช้ไม่ได้ 5-10 นาที)
    ควรอัปเดตตอนร้านปิด หน้าจอจะแสดงความคืบหน้าและกลับมาเองเมื่อเสร็จ
  • แอปเครื่องลูกเวอร์ชันใหม่มากับ Release ด้วย: เครื่องแม่เก็บไว้ที่ C:\PurimPOS\downloads
    และแจกให้เครื่องลูกอัปเดตเอง (ไม่ต้องใช้อินเทอร์เน็ตที่เครื่องลูก)
  • แอปหน้าร้านบนเครื่องแม่เอง: รัน Start > Purim POS Server > "ติดตั้งหรือซ่อมระบบ" อีกครั้ง
  • ถ้าขึ้นว่า "ยังไม่มี Release บน GitHub" = ผู้พัฒนายังไม่ได้ออกเวอร์ชัน (tag) รอแล้วลองใหม่

มีปัญหา
  • Start > Purim POS Server > "ติดตั้งหรือซ่อมระบบ Purim POS"  (รันซ้ำได้เสมอ ปลอดภัยต่อข้อมูล)
  • บันทึกการทำงาน:  C:\PurimPOS\logs  (launcher.log, backend.log, frontend.log, install-*.log)
  • เครื่องลูกหาเซิร์ฟเวอร์ไม่เจอ: ให้เครื่องแม่และเครื่องลูกอยู่วง Wi-Fi/LAN เดียวกัน
    และตั้งเครือข่ายของเครื่องแม่เป็น Private network

ถอนการติดตั้ง
  Settings > Apps > Purim POS Server > Uninstall
  (ฐานข้อมูล ไฟล์สำรอง และรูปสินค้า จะไม่ถูกลบ)
