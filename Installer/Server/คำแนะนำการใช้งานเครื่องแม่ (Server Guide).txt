==============================================================================
  🚀 แนะนำการเริ่มต้นและควบคุมเครื่องแม่ (Master Server) - ร้านปุริม POS
==============================================================================

โฟลเดอร์นี้ประกอบด้วยโปรแกรมควบคุมเครื่องแม่ และชุดคำสั่งเริ่มต้นเซิร์ฟเวอร์:

1. โปรแกรมและไฟล์สำคัญ:
   - "Purim-POS-Server.exe" : โปรแกรมควบคุมเครื่องแม่แบบหน้าต่าง (GUI) สวยงาม
                              * แสดงสถานะ Database, Backend API, Frontend แบบสดๆ
                              * แสดง IP เครื่องแม่ พร้อมปุ่มคัดลอก IP ส่งให้เครื่องลูกในคลิกเดียว
                              * ปุ่ม 1 คลิก "เริ่มต้นเซิร์ฟเวอร์" / "หยุดเซิร์ฟเวอร์"
                              * ปุ่ม 1 คลิก เปิดแผงควบคุม Sci-Fi / หน้าแคชเชียร์ POS / สำรองข้อมูล
                              * รองรับการย่อเก็บลง System Tray ข้างนาฬิกาได้อัตโนมัติ
   - "START_SERVER.bat"     : สคริปต์สำรองสำหรับเปิดเซิร์ฟเวอร์ผ่าน Command Line
   - "STOP_SERVER.bat"      : สคริปต์สำหรับหยุดเซิร์ฟเวอร์
   - "docker-compose.yml"   : คอนฟิกฐานข้อมูล PostgreSQL & Redis

2. การเปิดดูหน้าจอควบคุม (Master Command Deck):
   - สามารถกดปุ่ม "เปิดแผงควบคุม Sci-Fi" จากโปรแกรม Purim-POS-Server.exe
     หรือเปิดเบราว์เซอร์ไปที่: http://localhost:3000/master-control
   - ในหน้านี้จะแสดง:
     * Radar สแกนสัญญาณเครื่องลูกข่าย
     * IP เครื่องแม่ และ QR Code สำหรับสแกนด้วยแท็บเล็ต/มือถือ
     * สถานะเครื่องลูกที่เชื่อมต่ออยู่แบบเรียลไทม์ (Active / Online)
     * ยอดขายรวมประจำวัน และยอดขายแยกตามรายเครื่อง
     * การใช้งาน CPU / RAM / Latency ของฐานข้อมูล

3. การเชื่อมโยงเครื่องลูก:
   - ตรวจสอบให้เครื่องแม่และเครื่องลูกเชื่อมต่ออยู่ในวง Wi-Fi หรือสาย LAN เดียวกัน
   - นำ IP ที่แสดงในโปรแกรม Purim-POS-Server.exe ไปใส่ที่เครื่องลูก
