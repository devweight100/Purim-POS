คู่มือเข้าดูร้านจากนอกร้าน ด้วย Tailscale (ฟรี)
====================================================

ใช้ดู ยอดขาย / สต็อก / ราคาสินค้า / ประวัติบิล จากมือถือหรือโน้ตบุ๊ก ที่ไหนก็ได้
ข้อมูลยังอยู่ที่เครื่องแม่ในร้านเหมือนเดิม และ "คนนอกมองไม่เห็นระบบเลย"
เพราะเข้าได้เฉพาะเครื่องที่ล็อกอิน Tailscale ด้วยบัญชีของเจ้าของเท่านั้น
ไม่ต้องเปิดพอร์ตเราเตอร์ ไม่ต้องมี IP จริง ไม่ต้องเช่าโดเมน

หน้าที่เหมาะกับมือถือ:  /m   (ยอดขาย, สต็อก/ราคา, บิล, สรุปอื่น ๆ)


ขั้นที่ 1  สมัคร Tailscale (ทำครั้งเดียว)
------------------------------------------
1. เข้า https://tailscale.com  กด "Get Started" แล้วล็อกอินด้วย Google / Microsoft / Apple
   (ใช้บัญชีเดียวกันทุกเครื่องของเจ้าของ)
2. แพ็กเกจ Personal ฟรี เพียงพอสำหรับร้าน (ไม่กี่เครื่อง)


ขั้นที่ 2  ติดตั้งบน "เครื่องแม่" (คอมที่ลง Purim POS Server)
----------------------------------------------------------------
1. ดาวน์โหลด Tailscale for Windows จาก https://tailscale.com/download แล้วติดตั้ง
2. คลิกไอคอน Tailscale ที่มุมขวาล่าง > Log in > ล็อกอินบัญชีเดียวกับขั้นที่ 1
3. สำคัญ: ให้ Tailscale ทำงานตลอดแม้ยังไม่มีใครล็อกอิน Windows
   คลิกไอคอน Tailscale > Preferences (หรือ Settings) > เปิด "Run unattended"
4. ตั้งชื่อเครื่องให้จำง่าย (ไม่บังคับ) ในหน้า https://login.tailscale.com/admin/machines
   เช่น  purim-server


ขั้นที่ 3  ติดตั้งบน "มือถือ / โน้ตบุ๊ก" ที่จะใช้ดู
-----------------------------------------------------
1. มือถือ: ติดตั้งแอป "Tailscale" จาก App Store / Play Store
   โน้ตบุ๊ก: ดาวน์โหลดจาก https://tailscale.com/download
2. ล็อกอินบัญชีเดียวกัน แล้วกดเปิด (Connect / Active)
   ถ้ามือถือถามเรื่อง VPN ให้กดอนุญาต (Tailscale ใช้ VPN เฉพาะเครื่องในบัญชีเรา
   เน็ตอื่น ๆ ของมือถือยังใช้ปกติ)


ขั้นที่ 4  เปิดระบบจากนอกร้าน (เลือกวิธี A หรือ B)
-----------------------------------------------------
วิธี A (แนะนำ): ลิงก์ https ของเราเอง
  1. ในหน้า https://login.tailscale.com/admin/dns
     - เปิด MagicDNS (ปกติเปิดอยู่แล้ว)
     - เปิด HTTPS Certificates
  2. ที่เครื่องแม่ เปิด PowerShell หรือ Command Prompt "แบบ Run as administrator" แล้วพิมพ์
        tailscale serve --bg 3000
     ระบบจะแสดงลิงก์ประมาณ  https://purim-server.xxxx.ts.net
     (ดูลิงก์อีกครั้งได้ด้วยคำสั่ง  tailscale serve status )
  3. ที่มือถือ (เปิดแอป Tailscale ค้างไว้) เปิดเบราว์เซอร์ไปที่
        https://purim-server.xxxx.ts.net/m
     ล็อกอินด้วยผู้ใช้ของ Purim POS ตามปกติ
  4. เพิ่มเป็นไอคอนบนหน้าจอ: Safari > แชร์ > "เพิ่มไปยังหน้าจอโฮม"
     หรือ Chrome > เมนู ⋮ > "เพิ่มลงในหน้าจอหลัก"
  - ถ้าต้องการปิด:  tailscale serve reset
  - ถ้าคำสั่งไม่ตรงกับเวอร์ชันของ Tailscale ที่ติดตั้ง ให้ดูวิธีใช้ด้วย  tailscale serve --help
    หรือใช้วิธี B แทน

วิธี B (สำรอง): ใช้เลข IP ของ Tailscale
  1. ดูเลข IP ของเครื่องแม่ในแอป Tailscale (ขึ้นต้นด้วย 100.) เช่น 100.101.102.103
     หรือดูในหน้า https://login.tailscale.com/admin/machines
  2. ที่มือถือเปิด  http://100.101.102.103:3000/m
  - ตัวติดตั้ง Purim POS เวอร์ชัน 1.5.1 ขึ้นไป อนุญาตพอร์ต 3000 จาก Tailscale (100.64.0.0/10) ให้แล้ว
    ถ้าเปิดไม่ได้ ให้รัน "ติดตั้งหรือซ่อมระบบ" ใน Purim POS Server หนึ่งครั้ง
  - วิธีนี้เป็น http ธรรมดา (ข้อมูลยังเข้ารหัสอยู่ในอุโมงค์ของ Tailscale) แต่เพิ่มเป็นแอปบนหน้าจอไม่ได้เต็มรูปแบบ


ความปลอดภัย (อ่านสักครั้ง)
----------------------------
- อย่าแชร์บัญชี Tailscale ให้คนอื่น ใครอยู่ในบัญชีจะเข้าถึงเครื่องแม่ได้
- ถ้ามือถือหาย: เข้า https://login.tailscale.com/admin/machines แล้วลบเครื่องนั้นออก
  และเปลี่ยนรหัสผ่าน Purim POS ของผู้ใช้ที่เคยล็อกอินในมือถือนั้น
- ใช้รหัสผ่าน Purim POS ที่เดายาก หน้า /m เป็นแบบดูอย่างเดียว ขาย/แก้ไขไม่ได้
  แต่ถ้าเปิดหน้าจัดการเต็มจากนอกร้าน สิทธิ์จะเป็นตามผู้ใช้ที่ล็อกอิน
- เครื่องแม่ต้องเปิดอยู่และต่ออินเทอร์เน็ตอยู่ จึงจะดูจากนอกร้านได้
