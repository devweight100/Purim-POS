  💻 แนะนำการติดตั้งและเชื่อมต่อเครื่องลูก (Client Terminal) - ร้านปุริม POS
==============================================================================

โฟลเดอร์นี้ประกอบด้วยโปรแกรมสำหรับเครื่องลูก (จุดขายหน้าร้าน / แคชเชียร์):

1. ไฟล์ติดตั้งและตัวโปรแกรม:
   - "Purim POS Setup 1.0.0.exe" : ตัวติดตั้งลงเครื่องอัตโนมัติ พร้อมสร้างไอคอนหน้าจอ Desktop
   - "PurimPOS-Portable.exe"     : ตัวโปรแกรมแบบพกพา ไม่ต้องติดตั้ง ดับเบิ้ลคลิกเปิดใช้งานได้ทันที

2. ขั้นตอนการเชื่อมต่อไปยังเครื่องแม่ (Server):
   - เปิดโปรแกรม Purim POS ขึ้นมา
   - หากโปรแกรมถามหา IP เครื่องแม่ ให้กรอก IP ของเครื่องแม่ (ดูได้จากหน้าจอเครื่องแม่ หรือสอบถามผู้ดูแล)
     ตัวอย่าง: http://192.168.1.131:3000
   - หรือเปิดกล้องโทรศัพท์ / แท็บเล็ต สแกน QR Code จากหน้าแผงควบคุมเครื่องแม่เพื่อเข้าใช้งานผ่านเว็บเบราว์เซอร์ได้ทันที

3. บัญชีเข้าใช้งานเริ่มต้น:
   - สิทธิ์แอดมิน:  admin     / รหัสผ่าน: admin123  (PIN: 1234)
   - สิทธิ์แคชเชียร์: cashier1  / รหัสผ่าน: cashier123 (PIN: 0000)
