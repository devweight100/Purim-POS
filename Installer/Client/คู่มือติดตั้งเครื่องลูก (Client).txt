คู่มือติดตั้งเครื่องลูก (เครื่องขาย/แคชเชียร์) — ร้านปุริม POS
=====================================================

ไฟล์ติดตั้ง:  Purim-POS-Client-Setup.exe   (ติดตั้งได้ทุกเครื่องที่ใช้ขาย รวมถึงเครื่องแม่)
ดาวน์โหลด:   https://github.com/devweight100/Purim-POS/releases/latest  (หัวข้อ Assets)
             หรือจากเครื่องแม่ในร้าน: http://<ที่อยู่เครื่องแม่>:3000/api/client-app/download

ขั้นตอน
  1. ติดตั้งและเปิดเซิร์ฟเวอร์บนเครื่องแม่ให้เรียบร้อยก่อน
  2. ดับเบิลคลิก Purim-POS-Client-Setup.exe > Next > Install
     (ถ้า Windows ขึ้น "Windows protected your PC" ให้กด More info > Run anyway)
  3. เปิดโปรแกรม "ร้านปุริม POS" จากไอคอนบนหน้าจอ
     แอปจะค้นหาเครื่องแม่ในวง LAN ให้อัตโนมัติ
     ถ้าหาไม่เจอ ให้พิมพ์ที่อยู่ที่หน้าจอเครื่องแม่แสดง เช่น http://192.168.1.20:3000

หมายเหตุ
  • เครื่องลูกไม่ต้องติดตั้ง Docker / Node.js / ฐานข้อมูล
  • ลิ้นชักเงินและเครื่องพิมพ์ใบเสร็จต่อที่เครื่องลูกได้ตามเดิม
  • อัปเดตเวอร์ชันใหม่: อัปเดตเครื่องแม่ก่อน (มอนิเตอร์ร้าน > อัปเดตระบบ (GitHub))
    แล้วแอปเครื่องลูกจะพบเวอร์ชันใหม่และอัปเดตจากเครื่องแม่เอง
    หรือดาวน์โหลดไฟล์ติดตั้งตัวใหม่จาก Releases แล้วรันทับได้เลย
