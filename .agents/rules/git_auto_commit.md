# Git Auto-Commit Rule

**User Instruction:**
"โอเค หลังจากนี้ถ้ามีอะไรเปลี่ยนแปลงในโค้ดก็อัพขึ้น git พร้่อมใส่คอมเม้นที่สื่อความหมายให้เข้าใจด้วยนะเข้าใจไหม"

**Behavior:**
1. After making ANY logical set of changes to the codebase (e.g. after successfully completing a task or fixing a bug), automatically commit the changes to Git.
2. Ensure the commit message is meaningful, descriptive, and accurately reflects the changes made.
3. Automatically `git push` to the remote repository.
4. Inform the user in the chat that the changes have been pushed to Git.
